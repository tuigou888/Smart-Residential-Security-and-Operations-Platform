
## 1. 选型原则

成熟稳定优先、生态与人才可得、标准协议兼容、性能满足规模、自主可控与开源友好、总拥有成本可控。

## 2. 分层选型对比与结论

| 类别       | 候选                                  | 推荐                                                                       | 理由                           |
| ---------- | ------------------------------------- | -------------------------------------------------------------------------- | ------------------------------ |
| 后端框架   | Spring Cloud Alibaba / Go-Zero / .NET | **Spring Boot 3 + Spring Cloud Alibaba（中小规模可模块化单体起步）** | 生态成熟、政企认可、招聘容易   |
| 网关       | Spring Cloud Gateway / Kong           | **Spring Cloud Gateway**                                             | 与Spring体系一体               |
| 注册配置   | Nacos / Consul                        | **Nacos**                                                            | 注册+配置一体，中文生态好      |
| ORM        | MyBatis-Plus / JPA                    | **MyBatis-Plus**                                                     | 国内项目惯例，复杂SQL可控      |
| 权限       | Sa-Token / Spring Security            | **Sa-Token（或Spring Security+OAuth2）**                             | 开发效率高，功能全             |
| Web前端    | Vue3 / React                          | **Vue3 + TS + Vite + Element Plus**                                  | 上手快、组件生态好             |
| 大屏       | ECharts+自研 / DataV                  | **Vue3 + ECharts + 高德/Leaflet + 自研布局**                         | 可控、无授权费                 |
| 播放器     | jessibuca / flv.js / webrtc           | **jessibuca（FLV/WS/WebRTC全支持）**                                 | 低延迟、兼容好                 |
| 小程序/App | 原生 / Uni-app / Flutter              | **Uni-app（Vue3）**                                                  | 一套代码多端，团队技能复用     |
| 关系库     | MySQL / PostgreSQL                    | **MySQL 8.x**                                                        | 运维成熟                       |
| 缓存       | Redis                                 | **Redis 7**                                                          | 标准选择                       |
| 消息队列   | Kafka / RocketMQ / RabbitMQ           | **RocketMQ（业务）；Kafka（视频/AI大吞吐可选）**                     | RocketMQ业务特性好             |
| IoT接入    | EMQX / Mosquitto / 自研               | **EMQX 5.x**                                                         | 集群能力、规则引擎、百万级连接 |
| 时序库     | TDengine / InfluxDB                   | **TDengine**                                                         | 国产、压缩率高、SQL友好        |
| 检索/日志  | Elasticsearch                         | **ES 8.x**                                                           | 日志与记录检索                 |
| 对象存储   | MinIO / 云OSS                         | **MinIO（私有化）/OSS（云部署）**                                    | S3协议兼容                     |
| 流媒体     | ZLMediaKit / SRS                      | **ZLMediaKit**                                                       | GB28181支持完善、国内生态好    |
| 国标接入   | 自研信令 / WVP                        | **ZLMediaKit + wvp-GB28181-pro 参考**                                | 降低国标对接成本               |
| AI推理     | TensorRT / ONNX Runtime / Triton      | **边缘盒子+ONNX Runtime/TensorRT；中心可选Triton**                   | 分场景部署                     |
| 算法框架   | YOLO系列 / 厂商算法                   | **成熟算法采购+自研微调结合**                                        | 降低误报与交付风险             |
| 调度       | XXL-JOB / Quartz                      | **XXL-JOB**                                                          | 可视化管理                     |
| 工作流     | Flowable / Camunda                    | **Flowable（工单复杂时引入）**                                       | 二期按需                       |
| 容器编排   | Docker Compose / K8s                  | **单小区Compose；多小区K8s**                                         | 按规模选择                     |
| CI/CD      | GitLab CI / Jenkins                   | **GitLab CI + Harbor**                                               | 一体化                         |
| 监控       | Prometheus+Grafana+Loki+SkyWalking    | **全选**                                                             | 指标/看板/日志/链路完整        |

## 4. 选型风险与应对

| 风险             | 应对                                     |
| ---------------- | ---------------------------------------- |
| 微服务过早复杂化 | 一期模块化单体，二期按边界拆分           |
| 视频并发压力     | 子码流预览、按需拉流、流媒体横向扩展     |
| 厂商SDK绑定      | 抽象设备接入层，协议适配插件化           |
| AI误报           | 阈值可调、人工复核、持续样本优化         |
| 开源组件停更     | 关键组件保留商业支持备选（如EMQX企业版） |
