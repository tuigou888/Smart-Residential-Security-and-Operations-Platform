## 2. 部署架构图（云边协同）

```text
【中心云】K8s/Docker集群
  微服务群 + 数据库集群 + Redis + Kafka + ES + MinIO
  流媒体集群 + AI服务 + 监控(Prometheus/Grafana/Loki)
        ▲ 专线/互联网(TLS)
【小区边缘节点】
  边缘网关(协议转换/断网缓存) + AI盒子(本地分析)
  + NVR(本地录像) + 门禁控制器(本地白名单)
        ▲ 内网
【现场设备】摄像头/门禁/道闸/传感器...
```
